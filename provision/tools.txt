# Test and debugging tools. The HOST downloads them into cache/ (`winvm fetch`)
# and they are installed from there, so they also work for offline builds.
#
#   NAME  URL  [INSTALL ARGS...]
#
# How a file is installed depends on its type:
#   .zip         extracted to C:\Tools\NAME, added to PATH, Start menu "Test Tools";
#                "bin:SUBDIR" if the programs are in a subfolder (wildcards allowed),
#                "menu:a,b" to give only a.exe and b.exe a Start menu entry
#   .msix/.appx  installed for all users; "extract:DIR" also unpacks DIR from
#                the package to C:\Tools\NAME (for command-line tools)
#   .msi         msiexec /qn + ARGS
#   .exe         run with ARGS (must make it silent)
# URL "https://x/archive.zip!member" downloads only that member of the archive.
# Changing this requires `winvm build --force` (or install by hand + `winvm commit`).
